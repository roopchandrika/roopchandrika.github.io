01 · About

I like problems where AI, software and data meet, and the answer has to hold up in production.

I'm an AI Engineer at ThinkDigits, where I design AI agents, build Python backend services and develop rule-driven production scheduling systems. Before that I worked on healthcare AI systems, streaming data pipelines, ML model deployment and secure microservices, and on real-time payment systems handling 15M+ transactions a day.

One idea runs through my recent projects: the model proposes, the system verifies and a person decides. You'll see it in an agent that can never apply its own schedule changes, and in a fraud investigator that must cite evidence for every claim.
